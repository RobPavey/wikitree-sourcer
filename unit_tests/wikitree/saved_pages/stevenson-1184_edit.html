        How to Add Sources

        Citing sources is in our Honor Code. Add them below the bio like this:

        == Sources ==
        <references />
        * Stevenson, John. The Big Stevenson Book. Chicago, IL: Stevenson Publishing, 1914.

        Include inline references like this:

        The Stevenson farm was 20 acres.
        <ref>
        The Big Stevenson Book. Page 123.
        </ref>
